OWL demonstration library guide

This tiny demonstration tests the build, search and verification tools. It is not an emergency library or a medical manual.

First aid and medical shelf

A production build stores the FEMA CERT training manual and the WHO and ICRC Basic Emergency Care manual as ordinary PDFs. The demonstration does not include their contents.

How to find a book

Start with the category index, or select the precomputed search index in SEARCH.html. Search for the phrase compass navigation to find the small navigation fixture.
