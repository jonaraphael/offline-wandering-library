Search the offline library

Choose SEARCH/library.owl from this drive. The search reads small pieces of that file. Nothing is uploaded, and no internet or server is used.

Open the SEARCH folder and choose library.owl. Some phones copy selected files before reading them; use the static indexes if the file provider cannot read a large index.

Select an index to begin.

    Coverage and search help

    Results are ranked matching passages, including titles, categories, sources, filenames and extracted body text. Words are matched exactly after Unicode normalization; this version has no stemming, phrases, prefix search or language-specific word segmentation. A query can contain up to 32 different words. Results matching any word are considered. Common words can take longer because their full posting lists are streamed.

    PDF scans and images are not OCRed. Software and non-text maps are searchable by catalog metadata. See the build's coverage report and inventory. Archive results show the internal article name: open that archive in a compatible reader and find the article there. A browser cannot open an article inside a ZIM by itself.

    Local HTML can run search in modern desktop browsers with the File API. Android depends on the browser and file manager. iPhone/iPad Files previews often disable scripts; use the static indexes and ordinary documents in that case. Try this on each device before relying on it.
