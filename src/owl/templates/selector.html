    Unmet budget is an allowance for missing scope, not downloadable files or an exact size for missing documents. Temporary search work also lives on the SSD by default. Estimates cannot read your free space or guarantee the final index size. Run the plan command first.

    Search is built in phases. After verifying the temporary index, OWL releases its extraction database before generating browser search files. The peak uses the larger phase; the search and temporary-work rows are not simultaneous allocations.
