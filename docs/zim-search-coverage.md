# Offline archive search coverage

The table describes the pinned precomputed catalog. A drive includes the shards for its completed sources within the plan’s search allowance.
Complete directories include readable entries and redirects in the archive’s content namespace. Media tiles and internal archive data are outside this count.

Whole-file coverage uses the catalog SHA-256. Range coverage uses the exact byte count, a consistent mirror ETag and separate range digests. Both builders verify the complete archive against its catalog pin before attaching search.

The three English Wikipedia editions share chunks when title, path and redirect status agree. Each edition keeps its own set of chunk references. The pinned mini edition supplies 320,000 leads selected by direct redirect alias count. Of those, 318,112 have identical titles and paths in all three editions and are available in each. Lead records supplement the directory records, so the vector count can exceed the number of title paths.
