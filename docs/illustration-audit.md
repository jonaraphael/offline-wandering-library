# Illustration evidence addendum

On 18 September 2026, a second review checked the 15 additional OpenStax PDFs, seven FAO PDFs, and Pro Git against their catalog SHA-256 pins and visually inspected one representative physical page per file. All 23 original PDFs matched both their exact byte counts and their complete SHA-256 hashes in the SSD source cache before rendering. No source file was rewritten, recompressed or copied into Git.

Pages were rendered with Poppler `pdftoppm` 26.06.0 and inspected as page images and contact sheets. Text extraction was used only to locate candidate captions. The observations below describe the rendered source pages; they are not inferred solely from titles, captions, or image-object counts. Page numbers count from the first physical PDF page, including covers and front matter, rather than the printed page label.

All 23 sampled files support their existing `illustrated: true` classification. This closes the recorded visual-evidence gap for the added textbooks and agricultural guides. Combined with the original page checks in [source notes](sources.md#required-textbooks-and-illustrated-guides) and the individually rendered medical samples in [medical acquisition evidence](acquisition-medical.md#verification-and-search-limits), the current 50 directly readable illustrated teaching works have representative visual evidence. This is a sample, not a claim that every page is illustrated or a scientific, clinical, or pedagogical review of the books.

## Repeating the check

After verifying a source against its catalog hash, render the listed physical page without changing the PDF:

```sh
pdftoppm -f PAGE -l PAGE -singlefile -scale-to 1400 -png SOURCE.pdf /tmp/owl-page-review
```

Inspect the resulting image for the named figure or photograph and its surrounding context. This command creates a temporary review image; the original PDF remains the drive artifact. Book Dash EPUB illustration flags use separate package-and-reading-order checks documented in the education acquisition notes and are not counted among these 50 direct teaching works.
